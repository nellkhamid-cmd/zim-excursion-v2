# ЗИМ Галерея — лендинг «Запись на экскурсию», вариация 2

Вторая визуальная версия лендинга из папки `Лендинг экскурсия`. Контент (тексты по блокам, форма, юридическая информация) тот же, брендбук тот же: Jost + Quincy CF, #EC663B / #2A4F50 / #BBBBBA, прямые углы. Новые композиция, стиль и анимации. Статичный сайт: HTML + CSS + JS, без сборки. Открывается двойным щелчком по `index.html` (для file:// шрифты встроены в `assets/css/fonts-local.css`).

Сквозной приём — фирменная скошенная плитка как окно: фото, карта и форма открываются clip-path в форме плитки.

| Блок | Подача |
|---|---|
| Прелоадер | паттерн 3 × 3 собирается из плиток и улетает вверх |
| Шапка | зелёный блок логотипа, прячется при скролле вниз и возвращается при скролле вверх |
| Первый экран | светлый; рендер выходит из большой зелёной плитки, заголовок «прочерчивает» оранжевая плашка |
| Урбан-тур (как проходит экскурсия) | маршрут-лестница из пяти остановок: лекция о конструктивизме → стройка → квартиры-ячейки → Волга у порога → вопросы и книга; линия рисуется за скроллом и зажигает остановки |
| Три дома | зелёный зал; панорама собирается из трёх полос, триптих с параллаксом (на телефоне — свайп) |
| Что увидите | бенто-сетка, каждая ячейка открывается плиткой; паркинг — рендер |
| Почему выбирают | три карточки (культурный центр, безопасность, пространство); встречный скролл: фото едут вверх, тексты вниз (пин только от 1024 px) |
| Локация | текст слева, карта уходит в край окна и открывается плиткой от ЖК |
| Условия | оранжевый экран, цифры прокручиваются как счётчик |
| Отзывы | один крупный отзыв, авторы вкладками с автопрокруткой |
| Форма | фото на весь экран открывается по скроллу, панель формы поверх |

Файлы:

- `index.html` — страница
- `assets/css/main.css` — стили, mobile first
- `assets/js/main.js` — анимации (GSAP, ScrollTrigger, SplitText, Lenis), форма, вкладки отзывов
- `assets/js/map.js` + `assets/img/map.svg` — карта района (скилл brand-map, © участники OpenStreetMap — подпись не удалять)
- `assets/js/vendor/` — GSAP 3.15 и Lenis 1.3
- `assets/fonts/` — Jost (OFL) и Quincy CF с исправленной «Г»

Юридическая информация в подвале открыта. Фраза «Ставка от 6% годовых, полная стоимость кредита (займа) — от 18,652% до 25,643%» набрана переменной `--rate-size` — тем же кеглем, что цифра «от 6%» в блоке условий, на любой ширине экрана. Если меняете размер цифр условий, меняйте переменную, а не отдельные правила: фраза должна быть не меньше ставки.

Настройки внедрения — объект `CONFIG` в начале `assets/js/main.js`: адрес обработчика заявок, счётчик Метрики. Всё движение отключается при `prefers-reduced-motion`.

Перед запуском на боевом домене убрать `<meta name="robots" content="noindex, nofollow">` из `index.html`.
